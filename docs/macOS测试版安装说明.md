# 稿匣 macOS 测试版安装说明

这份安装包是测试版。

当前状态：

- 已做本地签名校验
- 没有做 Apple notarization
- 适合受控测试，不适合公开下载页长期分发
- 当前只验证过 `macOS arm64`

## 安装步骤

1. 双击打开 `稿匣_*.dmg`
2. 把 `稿匣.app` 拖到“应用程序”
3. 从“应用程序”里打开 `稿匣`

## 校验安装包

测试包里有 `SHA256SUMS.txt`。如果要确认 DMG 没有损坏，先在终端进入测试包目录，再执行：

```zsh
cd /path/to/稿匣_0.1.4_测试包
shasum -a 256 -c SHA256SUMS.txt
```

看到 `稿匣_0.1.4_aarch64.dmg: OK` 就表示校验通过。

## 第一次打开如果被拦

这是预期现象，因为当前测试包没有 notarization。

先试这一种：

1. 在“应用程序”里找到 `稿匣`
2. 右键
3. 选择“打开”
4. 在弹窗里再点一次“打开”

如果还是被拦，再用这一种：

1. 先双击打开一次，让系统弹出拦截提示
2. 打开 `系统设置`
3. 进入 `隐私与安全性`
4. 拉到页面底部
5. 找到刚才被拦截的 `稿匣`
6. 点击 `仍要打开`
7. 输入系统密码
8. 再打开一次应用

## 安装后点击没有反应

新 Mac 第一次打开未公证测试包时，可能不会弹出明确报错，只表现为点击图标没有反应。

先确认 `稿匣.app` 已经拖进“应用程序”，不要直接在 DMG 窗口里运行。

然后按下面处理：

1. 关闭 `稿匣`
2. 打开 `终端`
3. 执行下面这组 zsh 命令：

```zsh
APP="/Applications/稿匣.app"
xattr -dr com.apple.quarantine "$APP"
chmod +x "$APP/Contents/MacOS/novel-generator"
chmod +x "$APP/Contents/MacOS/novel-backend"
/usr/bin/codesign --force --deep --sign - "$APP"
open "$APP"
```

4. 如果命令执行后仍然没有自动打开，回到“应用程序”
5. 右键点击 `稿匣`
6. 选择“打开”
7. 在弹窗里再点一次“打开”

第一次启动可能需要等待 10 到 20 秒。打开后看到主界面，再导入测试许可证和填写模型配置。

如果执行命令后仍然没有反应，打开 `系统设置` → `隐私与安全性`，拉到页面底部，查看是否出现 `稿匣` 的放行按钮；有的话点 `仍要打开`，再回到“应用程序”里打开。

## 仍然闪退时检查权限

不建议打开电脑所有权限。按下面几项给 `稿匣.app` 放行即可。

### 必须放行

1. 打开 `系统设置`
2. 进入 `隐私与安全性`
3. 拉到页面底部
4. 如果看到 `稿匣` 被拦截，点击 `仍要打开`
5. 输入系统密码
6. 再打开一次 `稿匣`

### 可以手动打开的权限

如果仍然闪退，按下面路径给 `稿匣.app` 加权限：

1. 打开 `系统设置`
2. 进入 `隐私与安全性`
3. 进入 `完全磁盘访问权限`
4. 点击 `+`
5. 选择 `/Applications/稿匣.app`
6. 打开 `稿匣` 的开关
7. 退出 `稿匣` 后重新打开

如果系统弹出“是否允许访问桌面、文稿、下载、网络”等权限提示，选择允许。

不要给无关应用打开权限，也不要关闭系统安全功能。

## 第一次启动会发生什么

- 应用会在本地拉起自己的写作 backend
- 第一次打开可能会稍慢几秒
- 进入界面后，需要导入测试许可证，再填写模型配置和 `API Key`

## 测试许可证

测试包的生成、改稿、联网考据和模型类技能需要先导入有效许可证。许可证内容是一段签名 JSON，由测试发放方提供，格式类似：

```json
{"algorithm":"ed25519","payload":{"licensee":"测试用户","expires_at":"2026-06-30T00:00:00Z"},"signature":"..."}
```

永久许可证格式类似：

```json
{"algorithm":"ed25519","payload":{"licensee":"测试用户","permanent":true},"signature":"..."}
```

如果测试发放方要求绑定设备，先在许可证面板复制“当前设备码”，发回后再等待对方生成许可证。

如果没有导入许可证，应用仍能打开，也能查看和编辑本地项目，但生成类能力会提示先导入有效许可证。

## 当前不建议的环境

- Intel Mac
- 受公司 IT 管控的 Mac
- 不允许手动放行未公证应用的设备

## 测试时建议确认

- 能否正常进入主界面
- 能否创建作品
- 能否保存章节
- 能否打开技能库
- 能否导出整本
- 能否导出项目迁移包并导入成新作品

如果测试时要反馈问题，可以直接按同包里的《测试反馈清单》发回来。
