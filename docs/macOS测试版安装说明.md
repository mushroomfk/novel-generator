# 稿匣 macOS 测试版安装说明

这份安装包是测试版。

当前状态：

- 已做本地签名校验
- 没有做 Apple notarization
- 适合受控测试，不适合公开下载页长期分发
- 当前只验证过 `macOS arm64`

## 安装步骤

1. 双击打开 `稿匣_*.dmg`
2. 把 `稿匣.app` 拖到“应用程序”
3. 从“应用程序”里打开 `稿匣`

## 第一次打开如果被拦

这是预期现象，因为当前测试包没有 notarization。

先试这一种：

1. 在“应用程序”里找到 `稿匣`
2. 右键
3. 选择“打开”
4. 在弹窗里再点一次“打开”

如果还是被拦，再用这一种：

1. 先双击打开一次，让系统弹出拦截提示
2. 打开 `系统设置`
3. 进入 `隐私与安全性`
4. 拉到页面底部
5. 找到刚才被拦截的 `稿匣`
6. 点击 `仍要打开`
7. 输入系统密码
8. 再打开一次应用

## 第一次启动会发生什么

- 应用会在本地拉起自己的写作 backend
- 第一次打开可能会稍慢几秒
- 进入界面后，需要你自己填模型配置和 `API Key`

## 当前不建议的环境

- Intel Mac
- 受公司 IT 管控的 Mac
- 不允许手动放行未公证应用的设备

## 测试时建议确认

- 能否正常进入主界面
- 能否创建作品
- 能否保存章节
- 能否打开技能库
- 能否导出整本

如果测试时要反馈问题，可以直接按同包里的《测试反馈清单》发回来。
