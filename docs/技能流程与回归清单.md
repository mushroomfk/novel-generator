# 技能流程与回归清单

## 主流程

1. 左侧先选作品，再选章节。
2. `继续写` 是主对话入口。
3. 主对话默认走 `创意讨论`，直接调用 `/api/studio/brainstorm/stream`。
4. 主对话里如果选了专用技能，提交时会直接切到对应技能工作区，并把当前输入带过去。
5. `本章工作流` 处理拆场、诊断、续写。
6. `技能库` 负责专用工具、预设管理、文风库、文件与日志查看。

## 核心技能

- `创意讨论`
  入口：主对话、技能库
  执行：`/api/studio/brainstorm/stream`
  落盘：可手动记入 `项目记忆`
  回归：backend 单测；主对话入口已进 UI smoke

- `蓝图生成`
  入口：技能库
  执行：`/api/studio/blueprint/stream`
  落盘：写回 `blueprint`
  回归：backend 单测

- `分步架构`
  入口：技能库
  执行：`/api/generate/architecture/step/stream`
  落盘：一次性写回 `core_seed / character_design / world_building / plot_structure / character_state / blueprint / global_summary`
  回归：backend 单测

- `续写扩展`
  入口：技能库
  执行：`/api/studio/continue-project/stream`
  落盘：后端直接更新 `target_chapters / plot_structure / world_building / character_design / character_state / blueprint`
  回归：backend 单测

- `一致性检查`
  入口：技能库
  执行：`/api/studio/consistency/stream`
  落盘：可手动记入 `项目记忆`
  回归：backend 单测

- `人物复刻`
  入口：技能库
  执行：`/api/studio/character-replica/stream`
  落盘：人物卡保存到 `character_replica_profiles`
  回归：backend 单测；UI smoke 覆盖保存与重新载入

## 章节工作流

- `章节拆场`
  入口：技能库、本章工作流
  执行：`/api/generate/chapter-workflow/stream`，`mode=scenes`
  落盘：可写入 `blueprint`
  回归：backend 单测

- `章节诊断`
  入口：技能库、本章工作流
  执行：`/api/generate/chapter-workflow/stream`，`mode=diagnose`
  落盘：默认不自动改稿，输出诊断建议
  回归：backend 单测

- `章节生成`
  入口：技能库
  执行：`/api/studio/chapter-generate/stream`
  落盘：保存到当前章节正文
  回归：backend 单测

- `续写正文`
  入口：技能库、本章工作流
  执行：`/api/generate/chapter-workflow/stream`，`mode=draft`
  落盘：保存到当前章节正文
  回归：backend 单测

- `定稿整理`
  入口：技能库
  执行：`/api/studio/chapter-finalize/stream`
  落盘：保存修订稿；可更新 `global_summary / character_state`
  回归：backend 单测

- `场景润色`
  入口：技能库
  执行：`/api/studio/chapter-polish/stream`
  落盘：保存修订稿；可更新 `global_summary / character_state`
  回归：backend 单测

- `去 AI`
  入口：技能库
  执行：`/api/studio/chapter-humanize/stream`
  落盘：保存修订稿；可更新 `global_summary / character_state`
  回归：backend 单测，包含本地评分回归

- `批量生成`
  入口：技能库
  执行：`/api/studio/batch-generate/stream`
  落盘：后端直接写多个章节
  回归：backend 单测

## 风格与工具

- `文风与DNA`
  入口：技能库
  执行：样文分析、DNA 分析、融合、校准、参考库检索
  落盘：保存到 `styles`
  回归：backend 单测

- `提示词方案`
  入口：技能库
  执行：创建、编辑、启用、删除
  落盘：保存到 `prompt_presets`
  回归：backend 单测；UI smoke 覆盖创建与启用

- `XP 预设`
  入口：技能库
  执行：创建、编辑、删除
  落盘：保存到 `xp_presets`
  回归：backend 单测；UI smoke 覆盖创建与重新读取

- `知识检索`
  入口：技能库、主对话快捷跳转
  执行：项目知识检索与文件导入
  落盘：导入资料会写入项目知识库
  回归：backend 单测；UI smoke 覆盖主对话跳转、预填、检索

- `联网考据`
  入口：技能库
  执行：调用国内博查搜索，结合项目资料命中整理历史典故、史实出处和写作借鉴
  落盘：用户点击“存入资料库”后写入项目知识库
  回归：backend 单测覆盖未配置 Key、博查结果解析和模型整理失败后的可读返回

- `小说阅读`
  入口：技能库
  执行：只读查看章节
  落盘：无，纯查看
  回归：人工查看

- `文件浏览`
  入口：技能库
  执行：列出项目文件、读取、编辑
  落盘：保存到项目文件系统
  回归：UI smoke 覆盖读取后保存

- `运行日志`
  入口：技能库
  执行：读取、清空 app log
  落盘：日志本身在 `logs/app.log`
  回归：backend 单测覆盖底层；界面为人工查看

- `Prompt 历史`
  入口：技能库
  执行：读取、清空 prompt history
  落盘：记录保存在 `logs/prompt_history.jsonl`
  回归：backend 单测覆盖底层；界面为人工查看

- `Agent 执行轨迹`
  入口：后端接口，后续可做成界面查看工具
  执行：读取 `/api/studio/agent-trajectories`
  存储：记录保存在 `logs/agent_trajectories.jsonl`
  回归：backend 单测覆盖 Agent 执行后的轨迹写入和读取

## 当前回归口径

- `npm run verify`
  覆盖后端全部单测和前端生产构建

- `npm run backend:test`
  覆盖后端模型调用封装、项目写回、知识库、文风库、预设、人物卡、去 AI 评分回归

- `npm run build`
  确认前端编译通过

- `npm run verify:ui`
  覆盖建作品、章节编辑、主对话切技能、知识检索、人物卡保存回读、提示词方案、XP 预设、文件保存

## 还保留的边界

- 模型类技能的最终文案质量，仍然依赖实际模型配置，不在 smoke 里直接验字面结果。
- `小说阅读 / 运行日志 / Prompt 历史` 这三项本身是查看工具，不额外做写回动作。
