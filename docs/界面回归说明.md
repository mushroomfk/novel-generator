# 界面回归说明

这份说明针对当前工作台的浏览器层 smoke。

## 命令

```bash
npm run verify:ui
```

这条命令会执行 [scripts/verify-ui-smoke.mjs](../scripts/verify-ui-smoke.mjs)。

## 这条 smoke 会做什么

1. 用临时 `VITE_NOVEL_BACKEND_URL` 重新构建前端
2. 用临时数据目录启动 backend，不碰正式作品库
3. 用 `vite preview` 启动构建产物
4. 通过 Chrome 无头打开工作台
5. 在界面里实际完成下面这条主链

- 打开工作台
- 新建两部作品
- 重命名当前作品
- 删除另一部作品
- 导出当前作品迁移包，并把迁移包导入成新作品，确认章节正文保留
- 展开章节抽屉
- 选中章节
- 写入一段正文并保存
- 打开版本管理并确认自动快照状态
- 发起 Agent 章节计划并执行，确认计划卡、时间线和产物区可渲染；执行中停止按钮会向后端写入 workflow 中断请求，连接异常后可按 `task_id` 读取 workflow 摘要恢复时间线；如果结果区出现 `obsidian_maintenance` 产物，确认产物卡片可打开 Agent 自学习面板并按来源章节筛选 Obsidian 维护项
- 发送“资料分析 + 重写架构”类混合命令，确认优先进入架构路径
- 在项目页执行整书架构，确认统一 session 路径可用
- 在项目页发送讨论消息，确认讨论结果和建议按钮可渲染
- 进入技能库
- 打开 `知识检索`
- 搜索刚写进去的关键词并确认命中
- 选中带章节边界的章节后检索 Obsidian 关键词，确认结果预览没有显示后段专用笔记、未来双链、未来 Markdown 内链路径、未来标签值、未来图谱关系标签或已知未来笔记纯文本标题
- 在同一章节边界下执行 `联网考据`，确认本地资料命中没有引用后段专用 Obsidian 笔记
- 打开 `Obsidian 知识库`

## 依赖

脚本默认查找这个 Chrome 路径：

- `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`

如果路径不一样，可以先指定：

```bash
CHROME_BIN="/你的浏览器路径" npm run verify:ui
```

## 建议

适合在这些改动后跑一遍：

- 改了 `src/` 里的主工作台
- 改了小说文件夹列表和作品管理
- 改了章节编辑或技能区交互
- 改了前端运行时地址逻辑
- 准备做一次完整交付回归
