# 界面回归说明

这份说明针对当前工作台的浏览器层 smoke。

## 命令

```bash
npm run verify:ui
```

这条命令会执行 [scripts/verify-ui-smoke.mjs](../scripts/verify-ui-smoke.mjs)。

## 这条 smoke 会做什么

1. 用临时 `VITE_NOVEL_BACKEND_URL` 重新构建前端
2. 用临时数据目录启动 backend，不碰正式作品库
3. 用 `vite preview` 启动构建产物
4. 通过 Chrome 无头打开工作台
5. 在界面里实际完成下面这条主链

- 打开工作台
- 新建两部作品
- 重命名当前作品
- 删除另一部作品
- 展开章节抽屉
- 选中章节
- 写入一段正文并保存
- 打开版本管理并确认自动快照状态
- 发起 Agent 章节计划并执行，确认计划卡、时间线和产物区可渲染
- 发送“资料分析 + 重写架构”类混合命令，确认优先进入架构路径
- 在项目页执行整书架构，确认统一 session 路径可用
- 在项目页发送讨论消息，确认讨论结果和建议按钮可渲染
- 进入技能库
- 打开 `知识检索`
- 搜索刚写进去的关键词并确认命中
- 打开 `Agent 自学习`
- 刷新自学习状态、触发技能库检查、运行写作回归、运行模型审查、检查趋势、失败案例、技能版本区域并执行一次排程任务
- 打开设置弹窗，确认第二审查模型设置和“单独设置 Embedding”可显示
- 打开设置弹窗并关闭
- 打开架构总览，确认主区域能渲染，并点击统计卡片进入对应内容
- 打开提示词预设并创建、启用一个预设
- 打开 XP 预设并创建、回填一个预设
- 打开文件浏览并写回一段文本
- 打开 `人物复刻`
- 保存一张人物卡并重新点回填

已经覆盖：

- 前端真实渲染
- backend 与前端联调
- 项目创建

- 章节编辑保存

- Agent 整书架构执行
- Agent 讨论结果展示
- 技能库打开
- 知识检索结果回显

## 依赖

脚本默认查找这个 Chrome 路径：

- `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`

如果路径不一样，可以先指定：

```bash
CHROME_BIN="/你的浏览器路径" npm run verify:ui
```

## 建议

适合在这些改动后跑一遍：

- 改了 `src/` 里的主工作台
- 改了小说文件夹列表和作品管理
- 改了章节编辑或技能区交互
- 改了前端运行时地址逻辑
- 准备做一次完整交付回归
