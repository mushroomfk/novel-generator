# 人物复刻技能说明

这项技能用来把某个人物的公开表达、你的补充资料、当前作品上下文放到一起，整理成一套可复用的视角。

当前版本会给出这些结果：

- 表达特征
- 判断框架
- 判断原则
- 适用边界
- 视角回答

它不是角色扮演，也不是伪装成当事人发言。输出本质上还是基于公开信息和你提供资料做的近似推断。

## 在界面里怎么用

1. 进入技能库，打开 `人物复刻`
2. 填 `人物名称`
3. 填你要问的问题
4. 可选填 `希望强调`
5. 可选填 `补充资料`
6. 视情况勾上当前作品和当前章节上下文
7. 点 `开始复刻`

如果你常用某个人物，可以直接点 `保存人物卡`。保存后会记录：

- 人物名称
- 关注重点
- 补充资料
- 最近一次整理出的表达特征、判断框架、判断原则、适用边界

下次点左侧人物卡列表，会把资料直接回填到表单。

## 适合拿来做什么

- 判断某章开头该怎么取舍
- 用某种鲜明视角看人物选择是否成立
- 让不同人物框架来审视同一个剧情问题
- 给作者自己常用的一批思考视角做复用模板

## 不适合拿来做什么

- 当成真实人物本人背书
- 代替事实核查
- 处理强时效问题而完全不补资料
- 只靠一句名言就要求稳定复刻整个判断系统

## 资料怎么准备更有用

- 不要只贴语录，最好补一段这个人怎么判断问题的材料
- 能贴访谈摘要、文章观点、决策案例，比贴金句更有用
- 如果你只关心某一面，直接写进 `希望强调`
- 如果这次问题和当前项目强相关，建议带上作品上下文

## 当前存储位置

人物卡会保存在应用数据目录下的：

```text
character_replica_profiles/<人物名称>.json
```

这是本地文件，不会自动同步到别处。

## 回归建议

这块功能至少要检查这几件事：

- 技能卡能打开
- 可以保存人物卡
- 保存后列表能看到
- 重新点人物卡能把资料回填回来
- 运行一次复刻后，结果区能正常显示五个结果块
