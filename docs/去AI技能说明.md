# 去AI技能说明

这版 `去 AI` 不再只是丢一句“把模型腔去掉”给模型。

现在它分成三块：

- 一套固定的去痕规则
- 一套小说正文专用规则
- 一套本地效果回归评分

规则按中文小说正文场景整理，重点处理常见模型腔、解释腔、模板化结尾、人物对白同质化、抽象情绪直说、套版画面词和节奏过匀。

## 现在会重点处理什么

当前优先看这些问题：

- AI 连接词和套话，比如“此外”“值得注意的是”“某种程度上”
- 意义宣告句，比如“重要一步”“标志着”“奠定基础”
- 解释腔，比如“这意味着”“这表明”“让读者感受到”
- 口号式对照句，比如“不仅仅是……更是……”
- 总结式结尾，比如“总的来说”“未来可期”“迈出重要一步”
- 过匀的三连排比
- 套版画面词，比如“空气凝固”“命运齿轮”“故事才刚刚开始”
- 抽象情绪直说，比如“感到一种说不清的恐惧”
- 潜台词解释，比如“这个眼神意味着真正的危险”
- 对白动作标签重复，比如多人反复“低声说”“平静地说”
- 句长、段长和句首主语过于整齐
- 助手口吻残留，比如“当然”“希望这对你有帮助”

小说场景里最重要的一条是：少讲意义，多给动作、对白、停顿、物件变化和选择后果。

## 小说规则怎么工作

去 AI prompt 会明确要求模型按章节正文处理，不按说明文、公文或营销文案处理。处理顺序是：

1. 保住剧情事实、信息顺序、人物关系、伏笔和结局
2. 保住人物声音，避免所有对白都变成同一个旁白
3. 把抽象情绪改成可见反应、动作和环境互动
4. 删掉现成画面和金句式收尾
5. 打散过于整齐的句长、段长和句首主语

如果原文是完整章节，模型返回的修订稿明显短于原文，后端会拒绝这次结果，避免去 AI 变成剧情摘要。

## 在界面里怎么用

1. 打开技能库
2. 进入 `去 AI`
3. 选当前章节
4. 可选填补充要求，比如“保留冷硬气质”“对白别修得太顺”
5. 点 `开始去 AI`

运行完以后，结果区会多一块本地评分：

- 原文评分
- 修订后评分
- 分数变化
- 还残留的高频问题

这个评分不是模型评分，是本地规则扫出的回归分。它的作用是方便复盘，不是替代人工判断。

## 这版具体做了什么

- 去 AI 改稿改成独立 prompt，不再和普通改稿共用一套指令
- 在送给模型前，先扫原文里最明显的模板腔、画面套话、抽象情绪、对白标签和节奏问题，再把这些问题写进 prompt
- 模型返回后，本地再做一次前后对比，给出评分变化
- 如果模型没写修改说明，会用本地对比结果补一版简要说明
- 完整章节改稿时检查正文长度，明显缩水的修订稿会被拒绝

## 回归怎么做

后端补了固定回归样例，覆盖这些场景：

- 意义宣告和连接词
- 解释腔和总结句
- 模糊归因
- 助手口吻残留
- 三连排比
- 小说套版画面、抽象情绪、潜台词解释和句首主语重复
- 完整章节被模型缩写成摘要时的拒绝逻辑

Agent 自学习里的 `写作回归` 会额外跑一组去 AI A/B：

- A 组是带模型腔的小说片段
- B 组是预期改写后的小说片段
- 本地会比较前后评分、平均提升、通过率和正文长度比例
- 同时扫描当前项目的真实章节，挑出去 AI 风险高的片段组成项目样本池
- 回归报告会给出蒸馏规则，例如继续强化哪些残留问题、当前项目样本池最突出的问题

这组 A/B 不调用模型，速度快，适合作为每次自学习回归的门禁。它不能替代真实读者判断，但能持续发现去 AI 规则有没有退化。

Agent 自学习里的 `模型审查` 会做低频去 AI 裁判：

- 抽取项目样本池和历史 `chapter_humanize` 输出，让模型按自然度、人物声音、叙事张力、非模板化和误报风险评分
- 历史输出来自 Prompt 历史里的去 AI 任务，不会重写章节正文
- 模型认可的改法会写入 `.gaoxia/learning/humanize_evolution_rules.json`
- 后续章节去 AI prompt 会读取这些项目规则，让系统持续吸收当前作品自己的问题和有效改法

去 AI 裁判也接入后台智能巡检，不需要作者每次手动点模型审查：

- 章节正文保存后，会把 `humanize_review` 辅助任务写入 `.gaoxia/auxiliary_tasks.json`
- 手动做梦完成后，也会把 `humanize_review` 辅助任务写入后台队列
- 自学习心跳在排程已开启、且任务包含 `model_review` 时，会检查真实章节样本池和历史去 AI 输出；样本签名变化、项目规则为空、真实章节分数偏低或历史输出分数偏低时才触发去 AI 裁判
- 巡检状态记录在 `.gaoxia/learning/humanize_review_patrol.json`；同一批样本默认 12 小时内不重复审查，未变化样本 7 天后才允许复查
- 前台模型或检索任务忙时，辅助任务会延后，避免把章节写作和做梦链路拖慢

执行命令：

```bash
npm run backend:test
```

重点看这两个用例：

- `backend/tests/test_humanize_service.py`
- `backend/tests/test_studio_service.py`

## 边界

- 这是规则回归，不是“文学性自动评分”
- 分数高，不代表文风一定好，只代表常见模型腔更少
- 分数低，也不一定全错，某些句式在特定人物口吻里本来就能成立
- 现在这版主要针对章节正文，不是给说明文、公文、营销文案做的
